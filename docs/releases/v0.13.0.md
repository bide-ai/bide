**A run viewer.**

v0.13.0 adds `bide-view`, a read-only local page that shows what a run did, straight from its journal.

- **See a run.** An agent run's timeline: model turns, tool calls with their safety class, attempts, approvals with their k-of-n status, halts, and the end state. A plan flow's declared graph with the path the run took and a conformance check.
- **See where it stopped.** A run halted on an unknown outcome shows the call, its attempt and the exact `ResolveHalt` call that resolves it. A run paused at an approval gate shows "waiting for approval" and the gate's approvers.
- **See that it verifies.** Given a signed tree head or an evidence package, the page shows whether the run's records are all under the signed head. Given the approvers' keys, it also checks each approval signature and the k-of-n count ("2 of 3: signatures verified (ops, finance)"), against the policy the run recorded or one you state with `-need` and `-approvers`. It uses the same verification as `bide-audit`.

It reads SQLite, Postgres or an exported journal, serves on a loopback address only, opens the store read-only, and works offline. See the [run viewer guide](https://github.com/bide-ai/bide/blob/main/docs/guides/run-viewer.md).

Also: runnable `Example` tests for the main API, complete godoc, and bide on gsm v0.14.0.

API changes:

- New: the `cmd/bide-view` module; `sqlite.OpenReadOnly`, `postgres.OpenReadOnly`, `agent.ApprovalPendingStep` and `agent.ApprovalWait`.
- A run paused at an approval gate journals an informational `approval-pending:<call>` record; `approval-pending:` is a reserved step-name prefix.
- bide requires gsm v0.14.0.

The CHANGELOG has the details.
