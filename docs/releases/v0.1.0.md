First public release. bide is a Go library for building durable AI agents: a full agent framework (models, tools, typed flows, memory and RAG, MCP, multi-agent, human-in-the-loop) on one append-only journal that pairs four guarantees no other agent framework gives in a single library.

## What you get

- **At-most-once side effects.** A resumed run never re-charges a card or re-sends an email; effects are recorded on the journal, not replayed on recovery.
- **HA in one process.** Thousands of concurrent durable runs survive crashes and node handoffs. No cluster, no separate workflow engine.
- **Verifiable audit trail.** Every run emits RFC 6962 Merkle proofs, checkable offline without trusting the vendor.
- **Provably convergent state.** Governed shared state carries machine-checked convergence.

## The agent surface

Model adapters (OpenAI, Anthropic, Gemini), tools, the `plan` typed flow builder, durable timers and typed human-in-the-loop signals, MCP tool sources, retrieval and memory, and OpenTelemetry in one line.
