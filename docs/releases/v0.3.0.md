**Unknown outcomes a reconciler can settle safely, and on the record.**

When a side effect was attempted but its result was never recorded, bide halts the run rather than guess. v0.3.0 makes the next step, resolving that halt, safe to automate. Most systems without an idempotency key still leave a queryable record (a sent-message id, a row, a log line), so a reconciler can check it and call `ResolveHalt` itself. Two new options make that safe in time and complete on the record:

- **A grace period before deciding.** `WithMinHaltAge(d)` refuses to resolve a halt younger than `d`, measured from the attempt marker (now exposed as `ResumeHalt.AttemptedAt`) to now. A provider's record can lag the send by seconds; waiting keeps "unknown" unknown until the record has had time to appear. Too soon returns `*HaltTooYoung`, so the reconciler waits and retries.
- **Evidence in the journal.** `WithEvidence(v)` marks the injected result as reconciled and stores what the reconciler read, signed with the outcome. A later reader, or `bide-audit`, can tell a reconciled step from a clean one and re-check the basis for the decision.

<!-- docsnip: skip the v0.3.0 API as released; ResumeHalt is now OutcomeUnknown, cleared with ResolveHaltRef (see the durable steps guide) -->
```go
var halt *agent.ResumeHalt
if errors.As(err, &halt) {
    sent, record := providerSays(halt) // query the system of record
    if sent {
        _ = agent.ResolveHalt(ctx, store, halt.RunID, halt.ToolUseID, "sent (reconciled)", false,
            agent.WithMinHaltAge(30*time.Second), // do not decide before the record can settle
            agent.WithEvidence(record))           // journal the basis, signed with the outcome
    }
}
```

Both options are opt-in, and existing `ResolveHalt` calls compile and behave as before. The new record fields are omitted when unset, so journals and audit leaves written without them are unchanged. A person stays the fallback for the case no system can answer. Guide: [Durable steps](https://bide-ai.com/guides/durable-steps).

The README now lays out the unknown-outcome resolution ladder (retry what is safe, reconcile what is checkable, pause for a person otherwise), and is available in Simplified Chinese, Russian, Hindi and Arabic.

API changes in `agent`:

- `ResolveHalt` takes variadic `...ResolveOption`: `WithMinHaltAge`, `WithNow` and `WithEvidence`.
- New `*HaltTooYoung` error and `ResumeHalt.AttemptedAt`.
- `Record` gains `AttemptedAt`, `Reconciled` and `Evidence`.

Everything from v0.2.0 stands.
