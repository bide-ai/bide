Two runnable examples and the guide detail the v0.17.0 docs audit found missing. `examples/intake` mounts the approval intake (`WithGatePolicy`, `WithAuth` binding a bearer token to its approver, `WithPage`, `OnRecorded`) over an audited journal, takes a 2-of-3 refund gate with separation of duties through it, and checks the returned receipt against the signed heads; `examples/notify-routing` runs the notifier with routing by kind and approver, an escalation to a lead when on-call's endpoint is down, an all-clear, and a trail signed as it is written, and verifies it with `audit.VerifyNotifications`, which passes, fails on a trail with a record removed and reports the late acknowledgement. Both are in the root module, run offline and are tested. The approval guide now names `WithRateLimit`, `WithGlobalRateLimit`, `PageFiles`, `PageSHA256`, `Handler.Wait`, `EvaluateGate` and `GateReask`; the key custody guide `awskms.Config.GrantTokens` and `azurekv.Config.HostSuffixes`; the notifications guide the open trail and `WithNotifyUpgradeWindow`; the recovery guide that `RecoverLoop` re-signs runs waiting on a decision; known limitations what `postgres.WithoutMigration` does not check; Concepts the decision receipt; the README `bide migrate`; and the examples index the Azure Key Vault path of `hsm-signing`.
