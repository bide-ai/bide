`bide edit -run <id>` with a store (`-db`, `-postgres`, `-postgres-env` or `-journal`, the flags `bide view` takes, opened read-only) compares the file you are editing with the topology that run journaled, in a new panel, **Compared with a run**. It says SAME DIGEST (typed mode), NO DIFFERENCE SEEN (structural mode, where kinds, types and gates are not compared), DIFFERS FROM THE RUN with the changes the topology digest covers (including a change of order), or CANNOT COMPARE, and that a run paused under a different topology will not resume under the file. It compares topologies and nothing more: it does not say the run followed the file, and safety and assert lines, which are not in a journal or the digest, are not compared. It never blocks a save and does not change the weakened banner. A run that journaled no topology, has no digest yet, or journaled a topology that does not match its digest is named as such. The run is read once and again on **Reload run**. The path of the run on the canvas and the list of runs a change would affect come in later releases. See [Compare with a run](docs/guides/flow-editor.md#compare-with-a-run).
