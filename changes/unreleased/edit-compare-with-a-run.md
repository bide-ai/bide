Section: Added

`bide edit -run <id>` with a store (`-db`, `-postgres`, `-postgres-env` or `-journal`, the flags `bide view` takes, opened read-only) compares the file you are editing with the topology that run journaled, in a new panel, **Compared with a run**. It says SAME DIGEST (typed mode), NO DIFFERENCE SEEN (structural mode, where kinds, types and gates are not compared), DIFFERS FROM THE RUN with the changes the topology digest covers (including a change of order), or CANNOT COMPARE, and that a run paused under a different topology will not resume under the file. It compares topologies and nothing more: it does not say the run followed the file, and safety and assert lines, which are not in a journal or the digest, are not compared. It never blocks a save and does not change the weakened banner. A run that journaled no topology, has no digest yet, or journaled a topology that does not match its digest is named as such. The run is read once and again on **Reload run**. The page also draws the run's path on the flow (a ring and words per node: ran, started with no result recorded, paused at its approval gate; a dashed line over each connection taken), laid on the file by name with the session's renames, and lists what the file cannot show; the path is read by a few point reads per node. With a store, with or without `-run`, a second panel, **Unfinished runs this file would refuse**, lists the store's unfinished runs by the digest each recorded (one small record per run, never a history; at most 5000 runs, the first by run ID, said as "at least") and says which a drive under the file (resume, recovery or restart) would refuse: a different digest, or a topology that differs by what the digest covers; runs of another flow and runs that recorded no digest yet are counted apart. `-run` is no longer required with a store. See [Compare with a run](docs/guides/flow-editor.md#compare-with-a-run).
