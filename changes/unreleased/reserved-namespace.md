Section: Added

Reserved names for the cap and taint work that follows, and `agent.ErrToolUseIDInvalid`. Run IDs that start with `@cap/` are reserved for cap ledger runs: `Run`, `Stream`, `RunTyped` and `Session` return `ErrConfig` for one (`Run`, `Stream` and `RunTyped` already did for `@stop`; `Session` still accepts that id), as do the exported calls that write records to a run you name (`Approve`, `SubmitDecision`, `Cancel`, `ResolveHalt`, `AnswerInterrupt`, `Signal`, `Enqueue`, `Ack`, `ClaimAttempt`, `Step`, `Parallel` and the `audit.Record*` writers; reads such as `History` and `Status` are not refused, and these calls keep their existing behaviour for `@stop`), and `agent.IsReservedRun` (the stop control run or a cap ledger) and `agent.IsCapRun` report them; `Recover`, `RecoverLoop`, the notification sweep and its backfill, the run viewer, `bide approve -list`, `bide audit notifications` and `bide audit redactions` skip such a run. Step names that start with `slot:`, `cap-intent:`, `cap-reserve:` or `gate-reason:` are reserved as well (`Step`, `Parallel` and `ResolveHalt` return `ErrConfig`, `IsReservedStepName` reports them, and redaction treats the four as protected). A live model turn whose tool-use ID holds `#` now fails with `ErrToolUseIDInvalid`, which wraps `ErrModel` and `ErrProtocol` (so `middleware.Retry` and `middleware.Retryable` retry it, and the rejected turn is not journaled); resuming a journal that already holds such an ID does not re-check it, but `agent.Replay` used as the model of a new run treats the recorded turns as live and fails with `ErrToolUseIDInvalid` on a recorded `#` ID. Break risk: a deployment that already runs a run ID under `@cap/` can no longer start it, and the existing run is no longer recovered, listed by the viewer or `bide approve -list`, or read by the audit verbs, so a gate waiting in it would not be shown to an approver; rename such a run before upgrading. A `Step` or `Parallel` task named with one of the four step prefixes in a run that resumes fails with `ErrConfig`, and a model server that sends `#` in a tool-use ID fails every turn that calls a tool. Nothing in the engine writes a ledger or a reason yet.
