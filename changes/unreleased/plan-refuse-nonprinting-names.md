Section: Changed

plan's config reading (plan.Load, Validate, InspectConfig, and so bide check, bide view -config and bide edit) now refuses an identifier that holds a character that does not print: a control character, an invisible or direction-changing one (a zero-width space or joiner, a soft hyphen, the byte order mark, a bidirectional override such as U+202E), a space other than a plain one, a private-use or unassigned code point, a character that draws as a blank (the Hangul fillers, the Braille blank, the grapheme joiner), a combining mark or variation selector with nothing before it, or a space at either end. This also refuses some legitimate text: a word spelled with a zero-width non-joiner (Persian, Urdu), an Indic conjunct spelled with a zero-width joiner, an emoji joined sequence (a family, a flag), and a left-to-right or right-to-left mark; spell the name without it. It applies to the flow name, entry, in and out, node names and blocks, every reference in edges, switches, arms and else, join names, inputs and merges, and the assert lines (whose words may still be separated by any whitespace). Such a name could read as another in a diff or a review, and was accepted and drawn as written. The error wraps agent.ErrConfig and names the field and the character written out, for example `nodes[2].name "ch\u{202E}gra" holds a character that does not print (U+202E)`. As a second line of defence bide check, bide check -diff, bide view, every page it serves and its error messages write any such character that reaches them (a file name, a journal's topology, a step or predicate name) as \u{XXXX}; its JSON endpoints and the other commands are not filtered. Upgrading: a config with such a name now fails to load with that error, which you can search your logs for; rename the node (or fix the block, flow or reference) to a name of printing characters and a plain space, everywhere the config uses it (edges, arms, assert lines). Renaming a node changes the topology digest, so a run paused under the old flow does not resume under the renamed one.
