Section: Added

Trust documentation for security and risk reviewers in `docs/trust/`: a threat model (assets, actors, trust boundaries, and for each threat what bide prevents, detects and does not address), stability and support (the 0.x versioning policy, format versions, what stays verifiable across versions, deprecation), a comparison with Temporal, LangGraph and retries with idempotency keys, operations guidance (key custody, journal retention and archiving, backups, clocks, least-privilege Postgres roles), and release verification. Release archives and `checksums.txt` are now signed keylessly with cosign (GitHub OIDC), each archive has an SPDX SBOM generated by syft, and the release workflow verifies the published signatures in a `verify-signatures` job; `scripts/repro.sh` now checks only the archives, since the release also holds SBOMs and signature bundles.
