bide edit can reorder nodes and wiring elements and set the flow's name and its in and out type names (the second step of the editor's structure phase). A move exchanges two neighbouring list items as one splice (new engine operation Swap): each item keeps its own text, the comments directly above it and its trailing comment byte for byte, and whatever lies between them stays; the result is checked independently of the splice (the data with the two items exchanged, the same lines in another order, every line outside the pair where it was, each item with the comments it had), and moving back restores the exact bytes. A move into or out of the first place is refused when the config has no entry key, since the first node is then the entry; write the entry first. The wiring list is one Tab stop with a single Move pair for the selected element, and the flow settings are a closed disclosure, so the page does not cost a Tab stop per element. The API gains the operations move_node, move_wiring, set_flow, set_in and set_out, and View.In and View.Out.
