Section: Added

Added the redaction trail and its check: `audit.RedactJournal` erases the records of a plan accountably (it requires a reason, a ticket, an executor and a time; refuses a run no verified signed journal head covers unless `AllowUncovered`, which is recorded; appends a begin record before it erases and an end record after, to a trail named `redact:@log` in an event store that `audit.AuditedEventStore` or `audit.SignNotifyTrail` can sign and anchor), `audit.VerifyRedactions` and the new `bide audit redactions` verb. The check finds a deleted or changed trail record, records after the newest head, an unfinished pass, a tombstone no trail record names (an erasure made by hand), a tombstone whose name or leaf hash differs from the trail's (a tombstone's name is outside the journal's hashes, so the signed trail is what attests it), a record the trail lists that still holds content, and an erasure that ran without a covering head. `agent.RedactUsing` lets a different store than the journal's do the replacing. There is no command to erase yet.
