Section: Added

Added the redaction trail and its check: `audit.RedactJournal` erases the records of a plan accountably (it requires a reason, a ticket, an executor, a time and a signer, and signs every trail record with it, so a record planted by someone who can append to the event store is `BAD_SIGNATURE` under any head; `audit.SignRedactionTrail` verifies the earlier heads and every record before it signs a new head, and refuses a planted record; refuses a run no verified signed journal head covers unless `AllowUncovered`, which is recorded; appends a begin record before it erases and an end record after, to a trail named `redact:@log` in an event store that `audit.AuditedEventStore` or `audit.SignNotifyTrail` can sign and anchor), `audit.VerifyRedactions` and the new `bide audit redactions` verb. The check finds a deleted or changed trail record, records after the newest head, an unfinished pass, a tombstone no trail record names (an erasure made by hand), a tombstone whose name or leaf hash differs from the trail's (a tombstone's name is outside the journal's hashes, so the signed trail is what attests it), a record the trail lists that still holds content, a tombstone stamped at a time no pass that listed it carries, a run the trail names that has no journal in the input (a trail checked against no journal checked nothing), and an erasure that ran without a covering head; a tombstone is accounted for only by the pass that erased it (a later plan that lists it as already redacted does not launder an erasure made by hand), and a failed pass that the same plan later finished is a note. `-trail-db` and `-trail-postgres-env` read the trail from a store kept apart from the journal. `agent.RedactUsing` lets a different store than the journal's do the replacing. There is no command to erase yet.
