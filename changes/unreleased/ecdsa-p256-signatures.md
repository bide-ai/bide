Section: Added

`audit` signs and verifies with ECDSA P-256 (`ecdsa-p256`, `audit.ECDSAP256Signer`) beside Ed25519, ML-DSA-65 and the hybrid, for the HSMs and cloud KMS (AWS KMS, Azure Key Vault, PKCS#11) that cannot sign Ed25519: SHA-256 over the message, a 64-byte low-S `r || s` signature (a high-S or non-canonical one is refused), and a 65-byte uncompressed SEC1 public key written `ecdsa-p256:<hex>`, with `ECDSAP256SignatureFromDER`, `ECDSAP256SignatureFromRaw` and `ECDSAP256PublicKeyFromSPKI` for adapters; it works for approval decisions, tree heads, evidence, run certificates and grants, in the standalone `audit/verify` package and in every `-pubkey` and `-approver-keys` flag of `bide audit` and `bide view`. P-256 is not a hybrid half, and hybrid post-quantum keys inside an HSM stay deferred. No format changes for this: the scheme is a string in each artifact, and an older verifier refuses an `ecdsa-p256` artifact as malformed.
