`bide sample` writes a sample journal and opens `bide view` on it, with no code, no API key and no network: 14 runs produced by the real runtime on a scripted model and fake tools (refund agent runs completed, halted with an unknown outcome, halted and resolved, waiting at a 2-of-3 approval gate, approved with signatures, in progress, aborted and cancelled; plan flow runs completed, waiting, approved and halted; a run of durable steps only), two evidence packages with the log and approver keys that verify them (`bide audit verify-evidence`, `bide view -evidence -approver-keys`), three flow configs (a v1, a v2 that weakens the approval gate, and one with a violated assertion, for `bide view -config`, `bide check` and `bide check -diff -fail-on-weaken`), and a `README.txt` of what is inside and the commands to try. `bide sample -out DIR -no-browser` prints the viewer's address instead of opening a browser, and `-live` keeps one more run progressing while you watch. The runs are the same on every call (run IDs, states, start times and records), except for the random salt each record carries, so digests differ; the keys are fixed sample keys, not for anything real. The run viewer guide's run list, halted flow, risk map and violated-assertion screenshots are taken of it (`assets/demo/shots.sh`).
