Section: Fixed

A named pipe given where bide expects a file no longer hangs it: `bide view` (`-sth`, `-evidence`, `-approver-keys`, `-stop-policy`, `-pubkey` as a file), `bide edit` (a config swapped for a pipe after its check), `bide approve` (`-item`, `-approver-keys`, `-cert`, `-log-key`, `-verify-receipt`, `-tls-ca`), `bide stop -stop-policy`, the journal verbs (`-pubkey`, the JSON and signed-head files they read), `bide identity` and the identity preflight (`-policy`, `-params`, `-expect`, certificate chains, the files a policy names) and `bide-anchor -pubkey` open the file without waiting for a writer and refuse anything but a regular file, with the reason; a directory is refused the same way. A file that is a pipe by design is no longer accepted by these flags (use the file the pipe would write, or `-` where a flag takes standard input). Files with no size limit before now have one: 1 MiB for keys, policies, receipts, parameters and CA files, 256 MiB for the journal verbs' JSON and head files.
