Package `approvals` is an `http.Handler` an application mounts to take approvers' signed decisions over HTTP: `GET /pending` shows a gated call from the journal (tool, arguments, the arguments' SHA-256, the gate), and `POST /decisions` verifies a signed decision against the recorded call and the approver's enrolled key, then records it through the application's own journal, so an `audit.AuditedStore` signs it as it is written. Requests are strict JSON and size-bounded, rate limited per client and overall, and capped in concurrent work; `WithAuth` takes a mutual-TLS or identity check; a replay is a no-op; `OnRecorded` lets the application re-run the run. It adds `agent.DecisionStep` (the journal name of a decision) and `agent.RootRunID`. Single-approver gates and plan flow node gates are refused.
