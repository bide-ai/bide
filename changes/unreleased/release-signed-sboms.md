Section: Added

Each release now signs every SBOM and publishes one more. Each archive's SPDX SBOM gets its own keyless cosign signature (`<archive>.sbom.json.sigstore.json`), and `bide_X.Y.Z_modules.sbom.json` (with its `.sigstore.json`) is the SBOM of the published Go module set: what an application gets with `go get`, built by the new `scripts/module-sbom.sh` from the release's consumer module (the core, every library, the commands as tools) resolved only through the public Go proxy, and checked to list every published bide module at the release's version. The release workflow's `verify-signatures` job verifies each per-archive SBOM's signature, and a new `verify-module-sbom` job verifies the module set SBOM's. `docs/trust/verify-releases.md` shows how to verify the SBOMs and use them (grype, a CycloneDX conversion for Dependency-Track). The actions in the release jobs that can sign (cosign-installer, the syft installer and goreleaser-action) are pinned by commit SHA.
