Section: Added

New module anchor/awss3: the first production audit.Anchor, which writes every signed tree head as an object in an S3 bucket under Object Lock (compliance mode by default, governance only with AllowGovernance), reads it back and refuses a lock, retention or encryption weaker than configured, and keeps keys derived from the head so that the latest head of a trail and the head of any size are prefix listings with no mutable index; New refuses a bucket without Object Lock, versioning or a default retention, every request carries the expected bucket owner, writes are idempotent, and the package ships least-privilege IAM and bucket policies and a Reader and the bide-anchor command (verify, export, check) that verify the objects offline or with read-only credentials. It is tested against MinIO and a fake, never against AWS, and a run or trail ID in an anchored head cannot be erased, so it must hold no personal data ([anchoring guide](docs/guides/anchoring.md)).
