Section: Changed

States that bide view's graph and lists told apart by color alone now differ in shape or words as well, so they stay apart in greyscale, in forced colors and for a color-blind reader: a changed edge in the diff is dash-dot (an added one stays solid, a removed one a longer dash), a counterexample path is a heavy dotted line (the path taken stays a dash), a problem edge is a short dash, a warning node has a dashed box and a diamond mark where a problem has a circle, a row added by live mode carries a "new" badge, the run list's keyboard row has a marker and aria-current, and a stat's colored number has a glyph (check, cross, bang) on its label. A test now fails when two of these differ by color alone.
