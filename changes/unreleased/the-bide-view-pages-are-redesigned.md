Section: Changed

The `bide view` pages are redesigned. Every page opens with a verdict in large type, with a glyph and a line of why, and three or four key numbers: a run is `VERIFIED`, `COMPLETED`, `HALTED`, `WAITING FOR APPROVAL`, `FAILED` or `IN PROGRESS`; a config is `N POLICY VIOLATIONS` or `ALL ASSERTIONS HOLD` (or errors, undecided assertions, none); a diff opens with `APPROVAL GATE WEAKENED` when a gate was weakened; the run list opens with what needs a person. The cards under it are condensed to a label, a value and a line, with the detail in `details`. The flow graph (run path overlay, risk map, diff) is a hand-drawn layered SVG from an in-house layout, replacing the earlier grid: rounded nodes with a glyph per risk class or state, a `2/3` gate badge, edges routed around nodes, and the run path or counterexample as a flowing dash (still under `prefers-reduced-motion`). Hovering a node highlights the paths through it, clicking shows its details, and the graph pans and zooms; without JavaScript it stays a complete static SVG. The timeline has a glyph per record type, an anchor (`#record-N`) on every row, a collapsible payload with highlighted JSON and a copy button, and, for the records the journal timestamps (the start and attempt markers), an offset from the start with the UTC time on hover and a span bar. One set of design tokens (color, space, type scale) serves both themes, which keep following `prefers-color-scheme`. The JSON views (`/runs.json`, `/run.json`, `/config.json`, `/diff.json`) are unchanged, and the pages make no request to another host.
