Section: Fixed

Two places released a resource after handing the result to a caller that could act on it at once. `audit.AuditedEventStore` held a trail's slot until a deferred release ran after the head's answer was sent, so a caller that published the next head right away could find the slot taken; the slot is now released before the answer. `agent.RecoverLoop` called the `WithRecoverErrors` handler while the failing run still held its slot and in-flight mark, so a handler that waited on other work (with a small `WithRecoverConcurrency`) stalled it; the handler now runs after both are released. A new repository check, `internal/tools/sendcheck`, fails the Lint job when a goroutine sends or closes a result and only then runs a deferred decrement, release or unlock, with an allowlist for the orders that are safe, each with its reason.
