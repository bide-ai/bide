Section: Changed

New package audit/anchorobj (experimental): the SDK-free half of an object-store audit anchor, extracted from anchor/awss3 so that the Google Cloud Storage anchor and any later one name, encode and check anchored heads the same way: the object layout (partition hash, inverted size, head digest), the canonical object body and the checks a Reader makes on it, the equivocation check and the tripwire for run IDs that look like personal data. A backend supplies its own object format and partition tag, so an object of one anchor never validates as another's, and its own error values, so errors.Is and the text of its messages are unchanged. anchor/awss3 now uses it with no change in behaviour: the existing tests pass unchanged and new tests pin the object keys, bodies and partition names byte for byte.
