Section: Changed

Errors a newcomer is most likely to hit now say what to do next, with their sentinels (`errors.Is`) unchanged. A halted run (`*OutcomeUnknown`) names `agent.ResolveHalt` and re-running the run; a run waiting for approval (`*ApprovalPending`) names `SubmitDecision`; resuming a run with another input, flow, kind or saga mode suggests the original or a new run ID; `agent.New` with a nil model or journal names what to pass; a `plan.Load` config that names an unknown block says to register it and lists what is registered, and an unused block or duplicate node says how to fix it; a flow run recorded under another flow or topology digest says the flow changed and to resume with the original or start a new run ID; a provider's 401 or 403 says to check the API key and a 404 the model name and base URL; `sqlite.Open`, `sqlite.OpenReadOnly` and `postgres.Open` failures say what to check (a missing directory or file, a file that is not a journal, the DSN). Message text only: no behavior changes.
