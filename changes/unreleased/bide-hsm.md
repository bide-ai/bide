`bide-hsm`, a companion to `bide approve` for approvers whose signing keys are in an HSM, on a smart card or token, or in AWS KMS: `bide-hsm approve` is the same command (one implementation of the display, confirmation, signature, record and receipt) with `-key` naming the key by an RFC 7512 `pkcs11:` URI or an `awskms:` key ARN, and `bide-hsm pubkey` prints the `-approver-keys` entry that enrols it. References are parsed strictly (a PIN in the URI, an unknown attribute or a repeated one is refused, and no error repeats a value from the reference), the PIN comes from a file, an environment variable or a prompt on the controlling terminal (never a pipe), the token's own PIN pad (`pin-source=protected`), and a PKCS#11 key the token does not mark non-extractable is refused unless `-allow-extractable`. It is its own module under `cmd/bide` and needs cgo for PKCS#11 keys, so the `bide` binary stays pure Go and reproducible; it is installed from source (`go install github.com/bide-ai/bide/cmd/bide/bide-hsm@latest`), not in the release archives, and is tested against SoftHSM2 and a fake KMS client only.
