`plan.RegistryDescription` is version 2: each block and merge carries `untrusted`, `trusted` and `taint_exempt`, the description carries `taint_declared` (so a block that lists none declares none) and `taint_policy` (`plan.TaintPolicyDescription`, built from an `agent.TaintPolicy` by `plan.DescribeTaintPolicy`; `Describe` leaves it empty because the policy is the Builder's). A version 1 description is still read and says nothing about taint. `bide doctor -declarations` and `-diff` read such a description as a flow's declarations: a removed `Untrusted` source, a new `TaintExempt`, a removed policy, a lower gate or `require_provenance` turned off is weakened. Experimental.
