Signing keys can live in an HSM or a cloud key service behind `audit.Signer`: the new modules `signer/pkcs11` (Ed25519 through PKCS#11 `CKM_EDDSA`, tested against SoftHSM2, PIN from an environment variable or a file, never an argument, with `pkcs11test` for SoftHSM2-backed tests) and `signer/awskms` (Ed25519 through AWS KMS `ECC_NIST_EDWARDS25519`, tested against a fake client) sign tree heads, evidence seals, grants and approver decisions without the private key entering the application (`pkcs11.Config.RequireNonExtractable` makes the token confirm the key is non-extractable), and each signer signs once at open and checks every signature against the key's public key. Both refuse a token or key that cannot do Ed25519 instead of substituting another algorithm. KMS signs at most 4096 bytes, so a large evidence package cannot be sealed with it. The core module gains no cgo and no cloud SDK; see the key custody guide and `examples/hsm-signing`.
