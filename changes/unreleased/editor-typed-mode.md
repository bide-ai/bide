`bide edit -blocks <file>` and `flowedit.WithRegistry` / `flowedit.WithBlocks` make the flow editor typed. The editor then checks the config as `Load` does (by type name for a description file, labelled as not checked against the program), refuses an operation that connects what does not fit, adds the approval gate and safety a block declares in Go to the weakened banner without ever saying less than the structural check (so changing a block to one with no gate reads as the gate removed, and the structural "possibly" stays), and shows the digest, a palette of the program's blocks (a search, a filter for what fits the selected node, one Tab stop) and each node's types on the page; a connection by form, by drag or from the palette that does not fit is refused with plan's words, a target whose types differ is marked, and a text with errors against the blocks shows a NOT CERTIFIED banner. A port's drag handle no longer reaches over a neighbouring node in a dense or scaled-down flow.
