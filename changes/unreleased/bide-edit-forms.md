`bide edit`'s inspector has forms for the selected node's safety, block and approval gate. A form change is an operation the server applies to the file's text as a splice (`flowedit.ApplyOperation`), verified before it is returned, so the diff of an edit is the edit and comments, blank lines and the style of the lines around it stay; an operation the engine cannot splice safely is refused with the reason. The gate form edits a draft of the decisions needed, the approvers in policy order, separation of duties (`exclude_principal`) and the deadline (`timeout`), and each change to the draft asks the server what `bide check` says of the node with that gate and shows the answer under the form in the check's words (an out-of-range `need`, a repeated approver, an `assert` line the draft would break), so there is no second validator in the page. Apply writes the draft, Remove gate removes the gate, Undo and Redo restore the exact earlier text, a change returns the focus to the control, and the weakened banner follows each change against the baseline. The node's gate as the config declares it is in the view (`Node.Approval`).
