`gcpkms.Config.VerifyAttestation` makes the Google Cloud KMS signer verify the Cloud HSM attestation of its key version at `Open`, following Google's reference verifier: the manufacturer (Marvell) and owner (Google) certificate chains must build from pinned roots, both partition certificates must verify the attestation signature, and one attested EC object must carry the public key `GetPublicKey` returned, be non-extractable and generated on the HSM, and name the key version; otherwise `Open` fails with `gcpkms.ErrAttestation`. The roots are built in with pinned fingerprints and replaceable through `Config.AttestationRoots`; certificate validity periods are not enforced (Marvell's root has expired), the parser is bounds-checked and size-limited, and the check is off by default and needs an HSM key version. It is tested against the real attestation, chain and public key of a Cloud HSM P-256 key version, a real version 1 chain, and synthetic attestations and chains, and not against a live key service call.
