Section: Added

Added `bide journal redact` and `bide audit redactions`, and the library behind them (`audit.RedactJournal`, `audit.VerifyRedactions`, `audit.RedactionTrailName`, `agent.RedactUsing`). `bide journal redact` lists a plan as a dry run (each record by position, key, kind, length and leaf hash, never content, with a digest), and with `-execute -plan-digest` erases the records of a finished run into tombstones: it refuses a run that is not over, is leased, has a live parent, belongs to a session or has events in the event store, and refuses a run no verified signed journal head covers unless `-allow-uncovered` (recorded). It appends a begin record to a signed redaction trail before it erases and an end record after (who, when, why, ticket, the records by position and leaf hash), signs the trail's head with a key file and appends it to a file for the operator's anchor, and ends its report with the copies it cannot reach. `bide audit redactions` verifies the trail against its signed heads and the journals, and reports a tombstone no trail record names (an erasure made by hand), a tombstone whose name or leaf hash differs from the trail's (so a tombstone's name, which the journal's hashes do not cover, is attested by the signed trail), an unfinished pass, a listed record still holding content, and an uncovered erasure. A Postgres erasing role keeps its own DSN (`-redact-postgres-env`) because it can read nothing. There is no legal hold or second-person authorization yet.
