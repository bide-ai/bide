Generated SDK API reference: `docs/reference/api/` lists every exported constant, variable, function and type of every package in the published modules (the core module one page per package, every other module one page), each with its declaration and the first sentence of its doc comment, a pkg.go.dev link and a stability label (stable, experimental, or building block, not yet used by approval gates, the last for `audit/rfc3161` and the certificate verification core in `audit`). It is generated from the Go sources with the standard library only by `internal/tools/apiref`; `TestAPIReference` fails when a page is stale (`go test ./internal/tools/apiref -run TestAPIReference -update` rewrites them), when an exported symbol has no doc comment, or when a package has no label, and `TestStabilityPage` fails when the new package table in `docs/trust/stability.md` differs from the labels the generator uses. The docs site lists the reference in its Reference sidebar.
