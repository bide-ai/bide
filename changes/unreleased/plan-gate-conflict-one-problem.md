Section: Changed

A config approval block on a node whose registered block already declares an approval gate is now reported as one problem that says how to fix it (keep one, by removing approval from the config or the gate from the block) by Load, Validate and InspectConfig, and Build words a plan.Approval on a Tool with its own gate the same way; before, InspectConfig listed two problems for the one cause, neither with a remedy. The cause was that InspectConfig split an error's text at "; ", so any problem whose text held "; " (a node named "a; b", or a message with one in it) was cut in two and attached to no node: assemble, Build and the graph checks now carry their problems as a list that InspectConfig reads part by part, and the "; " workarounds in the loop and wiring checks are gone. The text of the errors Load and Validate return is unchanged.
