Section: Fixed

`bide check -diff` closes four gaps in how it compares `assert` lines. An assert line that held and now holds only vacuously (no terminal, or no path to its node, as when a new edge makes the flow cyclic) is reported as weakened; `plan.AssertionResult` gains `Vacuous` (set for such a hold, with a message saying why), and `bide view -config` shows `holds vacuously`. A line written twice is one assertion, with one weakened entry and one change line. Respelling a node name in quotes (or spacing) is no change in any assertion form, where only the approval form was recognised before (`plan.CompareAssertions`; `plan.RenameAssertion` writes a line with its node names renamed and quoted). A node renamed together with its assert line is a rename, not a removed assertion: the line follows the node the diff pairs as renamed, is still decided under the new name, and a rename the check is not sure of (its edges changed too) still reads as removed.
