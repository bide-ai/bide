Section: Added

A durable `audit.EventStore` in `store/sqlite` and `store/postgres`: `(*Store).EventStore()` keeps a run's event trail in the same database as its journal, in a `bide_events` table (created on `Open`/`New`; the table prefix and schema apply; the schema version is unchanged and an older database gains the table). `Append` is one insert-if-absent statement on primary key `(run_id, seq)`, committed before it returns, so it is crash-safe and writers racing for a position across connections or nodes have exactly one winner. New `audit.ErrSeqTaken`, wrapped by `EventStore.Append` when a different leaf already holds the position, lets a caller tell a lost race or a fork from a real failure (`MemEventStore` returns it too); a negative `seq` is now refused. New `audit/eventstoretest`, a conformance suite for any `EventStore` (append and load, byte fidelity, the same-leaf no-op, `ErrSeqTaken`, gaps, racing writers), run against the in-memory store and both new ones ([#239]).
