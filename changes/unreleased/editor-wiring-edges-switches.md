Section: Added

bide edit can add and remove edges, make a node a switch and remove the switch, and add, change, move and remove arms and set the else (the third step of the editor's structure phase), from the inspector's Connections section. Targets are chosen from the declared nodes; the editor refuses what plan.Load refuses (an edge or arm to an undeclared node, an edge into a join, an edge from a switched node, a switch on a node with an edge out, a self edge, a duplicate edge or arm, a switch with no arm: the only arm is removed with the switch). A new edge or arm that reaches a gated node by another way shows the weakened banner, from the same classifier as bide check -diff. New wiring is written in the style of the file, and as edge: [a, b] and when: [{pred: p, to: t}] where the file has none to copy; a plain scalar with a quote character inside a flow list is now written quoted, so the engine can edit its own output. The API gains the operations add_edge, remove_edge, add_switch, remove_switch, add_arm, remove_arm, set_arm, move_arm and set_else, Operation.Pred and Operation.To, and View.Wires.
