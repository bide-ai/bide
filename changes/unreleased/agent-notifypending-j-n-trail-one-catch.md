`agent.NotifyPending(ctx, j, notifier, trail, opts...)`: one catch-up sweep for the notifier, for an application that drives runs with `Run` alone and so has no `RecoverLoop` to find an event whose process died before it was recorded. It reads every unfinished run and delivers, as `WithNotifier` would and under the same event keys (so an event a drive also saw is delivered once), each run waiting at an approval gate and each run halted on an effect whose outcome is unknown. A halt is a marker with no result and no voiding not-started record, older than `WithNotifyHaltAge` (default 5 minutes), because a sweep cannot see a process that is still running the call. It returns the deliveries that failed, which the next sweep retries ([design](docs/design/notifier.md)).
