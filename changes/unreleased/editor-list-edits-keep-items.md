Section: Fixed

bide edit's list edits kept only the items at the start and the end of a list, so an edit that replaced an item in the middle or that changed both ends deleted and re-wrote the items it meant to keep: the comments above or beside a kept item were lost, and a block list turned into a flow list. This affected an approval gate's approvers list (set_approval, from the first release of the editor) and the inputs of a join (set_join_inputs, new). A list edit now keeps the longest common subsequence of the old and the new list exactly as it is, with its comments and the list's style, inserts the new items where they belong and deletes only the old items that are not in the new list; removing one approver is one deleted item and adding one is one inserted item. If you saved a gate edit made with an earlier editor, check the diff of its approvers list for comments that went missing.
