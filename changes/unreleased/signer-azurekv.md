Section: Added

Audit-log and approver signing keys can live in Azure Key Vault or Managed HSM: the new module `signer/azurekv` signs ECDSA P-256 only (Key Vault has no Ed25519), sending the SHA-256 digest with `ES256`, folding the service's 64-byte `r||s` to the low-S form audit verifies and checking every signature against the key's public key, with one self-test signature at open. It pins a full key identifier with its version (a version-less identifier is refused) and refuses a key that is disabled, expired, not yet valid, without the `sign` operation, exportable or on another curve; an HSM-protected key (`EC-HSM`, or any Managed HSM key) is required unless `Config.AllowSoftwareKey` is set. Credentials come from `azidentity` only, and errors carry only the operation, HTTP status and Azure error code, never a response body or token. It is tested against a fake client and the Azure SDK's in-process fake server, never against Azure; `examples/hsm-signing` gains `BIDE_AZURE_KEY_ID`. See the key custody guide.
