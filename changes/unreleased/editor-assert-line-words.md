Section: Fixed

`bide edit`: an `assert` line the grammar cannot read is now judged to name a node by one rule, whatever punctuation surrounds the name. The name counts when it stands in the line as a whole word or span, with a space, any punctuation or any symbol (not a letter, digit or combining mark) on each side, so `[audit]`, `audit-`, `audit/x`, `*audit*`, `_audit_`, `audit|`, a curly apostrophe or guillemets all name `audit`, `audits` and `audit2` do not, and a node name with spaces or punctuation is found as written. Removing or renaming a node such a line names is refused and names the line to fix first. The guide now says the refusal is a convenience and not a safety boundary: an unreadable line is never an assertion the check reads and stays reported as an error.
