Section: Added

Added the optional `agent.Redactor` store capability, implemented by `MemStore`, `store/sqlite` and `store/postgres`, which replaces one entry of a finished run with a redaction tombstone that keeps its position and audit leaf hash, together with `agent.PlanRedaction` (a dry run that lists records by position, name and leaf hash and never their content, with a digest), `agent.Redact`, `agent.NewTombstone` (a tombstone is read only in the exact byte form it is written, and now carries an optional `name` member, always written, that must equal the row it sits in, so `audit.JournalExport.Journal()` recovers the name of a redacted record and decision coverage from an export still lists a redacted approval), `agent.TombstoneName`, `agent.LeafHash`, `agent.CheckRedaction`, `agent.RedactionProtected` and `storetest.Redactor`, the conformance suite. A store refuses, writing nothing, a run with no end marker, a run with a live lease, a sub-agent's run while a run above it is not over, a session's runs, a protected record (the journal header, end markers, attempt markers, saga failures the saga compensation records and the records an approval count rests on), a tombstone that does not keep the leaf hash of the bytes it replaces (the store recomputes it), and an entry that changed since the caller read it. The core `Store` port is unchanged. `agent.Status` now reports a run whose `run:start` was redacted as started rather than not started. On Postgres the migration (run as the schema owner) creates a `SECURITY DEFINER` function, `bide_redact_v2`, that repeats every check server-side and builds the tombstone; the erasing role holds `EXECUTE` on it and no privilege on any table, so the application's role cannot erase and raw SQL by the erasing role cannot rewrite a record. A tombstone at a name a redaction never replaces is reported as corruption (`ErrStorage`) by every reader, and a tombstone's name, which is outside the leaf hash, is labelled "not attested" where a reader acts on it (`audit.NoteRedacted` now reads "redacted, name not attested"; `agent.RunStatus.StartRedacted`). There is no command yet and the erasure is not yet recorded in an audit trail; see the retention guide's section on erasing personal data for what it does not reach.
