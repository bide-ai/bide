The theme file format for bide's visual pages and bide theme check: a theme is a small JSON file of typed values (colours as #rgb or #rrggbb, fonts from a fixed list, numbers in ranges) that names a shipped base and overrides some of it, with strict keys (an unknown, repeated or differently cased key is an error). bide theme check parses a file and measures the resolved theme: WCAG text contrast 4.5:1 and non-text contrast 3:1, CIEDE2000 distance between the status colours (ok, warning, alert, info at least 20; the gated, side-effect, idempotent and idle colours at least 10 from every other), a colour-blindness check (a warning for your theme; the shipped themes must pass it), and a polarity check (alert warm and nearer red than warning, ok not). It exits 1 on a theme that fails. See docs/guides/themes.md and docs/design/themes.md.
