Section: Added

The records that resolve something a person was told about now note when they were written (`recorded_at`, `Record.RecordedAt`, canonical RFC 3339 UTC to the millisecond): a single approver's decision (`agent.Approve`, which now takes `WithClock`), an interrupt answer and a signal (`AnswerInterrupt` and `Signal`, which take `WithClock` too), the result `agent.ResolveHalt` injects (the resolver signs nothing, so the time is the writing process's unsigned claim), a run's `run:complete`, `run:aborted` and `run:cancelled` markers and a saga's `run:cancel-requested` (`agent.Cancel` now takes `WithClock`; `agent.Status` reports `RunStatus.EndedAt`). The clock is `WithClock`, else the run's, else the wall clock; the first write sets the time. It is informational like `started_at`: no gate, claim, replay or recovery pass reads it, the journal format tag is unchanged, a record from an earlier version has none and is reported as having none, and a clock with no canonical form records none. `bide view` places these records on the timeline and shows the end and resolution times in the verdict, the `ended_at` and event `recorded_at` in its JSON view; `bide audit verify` prints a proven record's time and `bide audit verify-evidence` adds it to a tool call's or step's line. `bide audit notifications` now judges an all-clear owed for a single-approver gate or a `ResolveHalt`-resolved halt against `-grace` from that record's time, so `all_clear_untimed` is reported only for a journal an earlier version wrote; `agent.JournalNotifyEvents` returns a `ResolveHalt`-resolved halt as an event that is no longer current.
