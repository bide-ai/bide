Section: Fixed

The core module and its test code build on Solaris and illumos again (`go vet ./...` was failing in the core, `flowedit` and `cmd/bide-anchor`): the tests that make a named pipe are built only where `syscall.Mkfifo` exists (Linux, macOS, FreeBSD, NetBSD, OpenBSD, DragonFly), and `notify/relay`'s state-file lock, which used `syscall.Flock`, now builds everywhere. On Solaris and AIX (not illumos, which has `Flock`) a relay refuses a `StatePath` at start with `exclusive file locks are not supported on this platform`, as on any platform without a file lock; it never runs two relays on one file unlocked. The SQLite-backed modules (`store/sqlite`, `govern/sqlitelog`, `cmd/bide` and the modules that import them) still do not build on DragonFly, Solaris and illumos, because `modernc.org/sqlite` does not support them.
